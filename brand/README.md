# Brand

The mark is the hinny's head: `hinny-mark-light.svg` (dark ink, for a light ground) and
`hinny-mark-dark.svg` (light ink, for a dark one), the same paths as
`website/public/hinny-mark.svg`. The project's README shows it.

The artwork is licensed like the code (MIT or Apache-2.0). The name and the mark identify this
project; please don't use them for other projects.
